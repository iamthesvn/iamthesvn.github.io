# Scalar and Compound types

In Rust, types are classified as scalar or compound based on whether they represent a single value or a collection of values. Scalar types represent single values:

1. signed integers
2. unsigned integers
3. floating point
4. char
5. bool
6. unit type

Compound types include tuples, arrays, slices, structs, and enums. Suffix annotation can also be used to specify the type of a literal.
